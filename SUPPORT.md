# Get help and participate

Start with [Troubleshooting](docs/troubleshooting.md). For access to an experience, a shared workspace, or Enterprise notes, ask the operator responsible for that service.

For a reproducible widget bug or a feature proposal, use [this repository's issues](https://github.com/sukruburakcetin/map-ex-test/issues). Search existing reports before opening a new one. Include your widget and host versions, the shortest steps, the expected and actual results, and a sanitized screenshot or first relevant error if helpful.

For a question that could help other users, use Discussions if the repository enables it. If Discussions is unavailable, use an issue with a clear question and relevant context. Please follow the [community standards](CODE_OF_CONDUCT.md). Use the [private reporting route](SECURITY.md) for security concerns.
