# v6.81 camera projection and independent outline halo
Requires v6.80. Rebuild/restart/reload. Keeps the static SVG center and on-ground Graphic. Adds a pointer-transparent CSS outline with 1800ms scale/fade cycle; no 3D symbol swaps or new SDK graphics/layers. Native center remains visible even if halo cannot be projected. Reduced-motion users and browsers without Web Animations receive only the steady marker. Tracking uses one RAF owner, at most 30 projection attempts per second while camera/terrain changes; settled geometry/sampler/viewport skips projection. CSS runs independently. Same-image updates preserve the halo cycle; disposal cancels animation/RAF and removes element. SceneView stalls may still affect presentation; no claim of GPU flicker fix.

Cone previously required groundView.elevationSampler for camera-dependent sizing. For an explicitly empty Ground.layers, helper now projects against z=0 rather than falling back to zoom. With elevation layers it still requires valid rendered terrain and never assumes zero height. No elevation network calls introduced. Existing 60px direction-length target, physical radius caps and 40–96px screen bounds retained; extreme distance/perspective can still shorten/hide the wedge. This is not a constant-size screen arrow, nor a promise of 60px under every angle. Halo uses same rendered-ground helper for alignment. No source Z copied into flat-ground projection.

Source changes SelectionPulse.ts and runtime drawCone/import. Sequence/hover/coverage algorithms unchanged. Tests add flat-ground same-zoom projection comparison, halo identity/projection/cleanup and terrain availability. --uninstall returns to v6.80 static target without this halo or flat-ground correction; rebuild/reload needed.

If the map container is CSS-static, halo temporarily establishes relative positioning for container-local coordinates and restores its inline value on cleanup, unless another component changed it. Existing positioned containers are left as-is. Browser validation checks halo center against projected ground coordinates.
