# Note selection and expandable sheet

`FieldNoteMap.focusNote` owns one transient selection graphic. Show on map selects it and keeps the existing camera/image navigation. SDK hits on Local/selected workspace markers select it without moving the camera; Enterprise hits keep their existing popup actions and highlight their point. The normal diamond keeps its original symbol. `nativeNoteHighlight.ts` uses ArcGIS GraphicsLayerView.highlight and opens the selected graphic's popup. Any new map click clears the owned highlight/popup before picking; closing the popup releases native handles too. Late SDK/popup responses check selection ownership. Enterprise map clicks retain their existing native popup/highlight and action behavior. Selecting another note replaces the highlight; cleanup invalidates pending SDK work. This never publishes or saves a local copy.

`mapGraphic.ts` owns unchanged note symbol descriptors; native selection styling belongs to ArcGIS. `FieldNotesPanel.tsx` owns the in-memory expanded state. Its native button grip supports touch, mouse, Enter and Space and exposes aria-expanded. Expanded height is 92% of the widget's available height; the default stays capped at 300px/65%. Lists continue to scroll inside the sheet. This is a click/tap toggle, not a draggable resize control.

The coverage click fast path requests an SDK hit test when note markers are available so note clicks retain priority over imagery. Without note targets, existing coverage picking remains unchanged.
