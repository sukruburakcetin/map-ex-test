# Open your first street-level capture

You need a browser and access to an Experience Builder app. If the app already includes Mapillary Explorer, go directly to step 4. If you are building an app, use Developer Edition and have permission to configure the experience and access its map.

1. **Choose and install Experience Builder.** Check the supported host, Node.js version, and package manager before installing. Follow steps 1 and 2 in the [installation guide](installation.md#1-choose-your-host-version).
2. **Install Mapillary Explorer.** Copy the widget into the host's extensions folder. Install its dependencies from the host client folder, using the command for your version. [Widget files and dependencies](installation.md#3-put-the-widget-in-the-correct-folder)
3. **Connect a map.** Start the client and server, open the builder, and add a Map widget and Mapillary Explorer. In the Explorer settings, select the Map widget. Preview the experience. [Start and configure the host](installation.md#5-configure-and-start)
4. **Find a capture.** Move to an area with Mapillary imagery and zoom in until individual capture points appear. Point at a capture to preview it, or select a point directly on a touch screen.
5. **Open and verify.** Select the capture. The image should open in the viewer and the map should indicate the selected capture. Try a nearby point to confirm that the viewer follows your selection.

If the widget panel is missing, or the map shows no captures, follow the [troubleshooting checks](troubleshooting.md). Once the first image opens, try [filters and image comparison](user-guide/README.md).
