# Explore coverage and analysis tools

These workflows use the active map and selected capture. Availability depends on the Builder configuration, data coverage, and the services connected to the experience. Start by [opening a capture](../getting-started.md) and checking the [image information](image-information.md).

| Goal | Workflow | What to check |
| --- | --- | --- |
| Review imagery coverage | Open **Analyze Coverage** and follow the coverage guide in the viewer. | Coverage describes available imagery, which can change with filters and zoom. |
| Plan a capture route | Set the start and end points in the route controls, select a configured provider, and generate a route before opening the preview or exporting GPX. | Preview is a simulation. Check the route against local travel conditions before using the export. |
| Explore sequence elevation | Enable the elevation profile for a selected sequence and use its indicator to follow the confirmed capture. | Camera altitude and terrain data are estimates. |
| Inspect capture-time sunlight | Enable solar modeling on a capture with a timestamp and location. | The calculation uses capture metadata. The scene and photograph can show different lighting. |
| Explore reconstructed geometry | Open the point-cloud controls on a capture with an available reconstruction. Inspect the result and select the appropriate tool before measuring or exporting. | Check alignment and calibration before relying on measurements or exported coordinates. |

!!! tip "Choose the right view"
    If a map tool is unavailable, check the selected capture and the active map type. Some point-cloud analysis and scene-lighting controls depend on a 3D view.
