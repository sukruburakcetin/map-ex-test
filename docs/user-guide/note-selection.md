# Select and view a field note

Click a note marker or choose **Show on map** from its row. The selected note is highlighted; select another note to change the highlight. Shared Enterprise markers also offer their normal popup actions. Selection does not save or publish a note.

To make the notes sheet taller, click or tap its handle. Keyboard users can focus the handle and press Enter or Space. Activate it again to collapse. It is a toggle, not a drag-to-resize handle; the list scrolls inside the sheet.

Creating a Local note and publishing a shared note are separate actions. Use the configured sharing/workspace action only when you intend to publish.
