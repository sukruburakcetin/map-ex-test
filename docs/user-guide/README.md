# Use Mapillary Explorer

Open the Experience Builder app and look for Mapillary Explorer. Your app builder chooses where the panel appears and which optional tools it shows. If you are adding the panel to an app yourself, start with [Getting started](../getting-started.md).

1. Zoom to a street with Mapillary coverage. Select an individual point to open an image. Use the map to find another capture, or use the nearby imagery controls where available.
2. Open the filter controls to narrow coverage. If regular photos disappear, set the panorama filter back to **All**.
3. Use image information to see capture details. Use Time travel when offered to compare thumbnails from other capture dates.
4. Open Notes to review or record observations. Select the note source before searching or publishing. Access to shared sources depends on your account and the app's configuration.

Use the builder to add, configure, or remove a widget instance. Preview and save your changes, then publish them through the host's normal process. For a deployed widget update, follow the [publisher guide](../publishing.md). Workspace memberships, shared data, and service permissions are managed through their own services.
