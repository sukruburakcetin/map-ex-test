# Search and sort your notes

Use the search field in the **Local** or **Enterprise** tab. It matches description, category, follow-up/resolution and status, ignoring case and accents. When you type several words, all words must match, but they can occur in different fields.

- **Local:** searches all notes saved in this browser's collection.
- **Enterprise:** searches only records already loaded in that tab. Use **Load more** to include additional pages, even when the current pages have no matches.
- **Workspace:** uses its separate shared contribution search; see [workspace controls](workspace-readability.md).

Use the clear button or Escape to reset the search. Selecting/editing a result acts on that original note. Searching does not move markers, change stored notes or publish anything.

**Export**, **Import** and confirmed **Clear Local** still apply to the complete Local collection, not just visible search results. A search resets when its list closes/unmounts or its tab changes.

## Sort notes

Each Local, Enterprise and Workspace list has a compact **Sort** menu:

- **Date:** newest first (default), or oldest first. Uses the note creation date, not its last edit time.
- **Name:** A–Z or Z–A using the active language's alphabetical and natural-number order. Uses the note title; notes without a title use their displayed category.
- **Status:** Open → In progress → Completed → Dismissed, or the reverse. Missing status is treated as Open; unrecognized statuses stay at the end.

Local sorting covers the full collection, or its current search results. Enterprise and Workspace sorting covers only loaded results. Select **Load more** to include more records; the combined loaded list is sorted again using your selected order. This is not a global sort of records still on the server.

Changing sort does not download records, change search filters, move map markers, modify saved notes, change permissions or alter export contents. Notes with equal sort values keep their existing relative order. Each list remembers its choice while mounted; reopening a remounted list starts with newest first.

## Compact panel and expansion

Service status and the Enterprise account share a wrapping header line. Search and Sort share a row when space permits; on narrow screens they wrap. The search field keeps its accessible name even though its separate visible label is removed. Counts and loaded-record guidance remain below the controls.

Activate the sheet's grip button with a click, tap, Enter, or Space to expand upward. The bottom stays anchored while the height changes smoothly; activate it again to collapse. System reduced-motion preferences disable the animation. Scrolling the active source still reaches all notes without requiring expansion.
