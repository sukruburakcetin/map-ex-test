# Nearby places · Overture

Places is a built-in, optional exploration feature. It adds Overture points of interest alongside Mapillary imagery, coverage and detected objects.

Configure **Offer Places layer** and **Places service URL** in widget settings. The service provides vector tiles for map display and bounded requests for picking, details and search. Viewers enable Places when they want to explore nearby locations.

See [Places service setup](OVERTURE-PLACES-SERVICE.md) for configuration, local testing, service requirements and compiled-application administration.

The viewer includes category and quality filters, closest-first search, paging, map/list selection, imagery exploration, field-note actions and a minimizable Places panel. Service hosting and dataset import remain administrator tasks, separate from the viewer interface.
