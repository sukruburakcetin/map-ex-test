# Translation glossary (pilot)

| English | Turkish | Meaning |
|---|---|---|
| image / capture | görüntü / çekim | A particular Mapillary photograph; use çekim for date comparison. |
| sequence | görüntü dizisi | A capture sequence, not a route generated by the widget. |
| coverage | kapsama | Mapillary imagery availability on the map. |
| bearing / heading | yön / kamera yönü | Camera compass direction; avoid a surveying term unless the UI needs it. |
| legend | lejant | Map symbol explanation; distinguish it from data itself. |
| point cloud | nokta bulutu | 3D reconstructed points. |
| Time travel | Zamanda yolculuk | Comparison of captures from different dates. |
| preview | önizleme | A preview, not the active viewer selection. |
| panorama | panorama | A 360-degree capture; not a single directional field of view. |
| organization ID | kuruluş kimliği | Numeric Mapillary organization identifier. |

Draft terminology requires native review in the product context. Brand names such as Mapillary and Overture Maps remain unchanged. Do not translate user content or invent translations of proper place names.
