# Report a security concern

Report suspected vulnerabilities privately to the maintainer through the upstream project's security policy. Include the affected version, impact and reproduction details, with credentials and private data removed. Use public issues for ordinary bugs. [Private reporting instructions](https://github.com/sukruburakcetin/mapillary-explorer/blob/main/SECURITY.md)

When publishing, review HTTPS, service permissions, and access with a normal viewer account. Keep privileged secrets in the backend and out of browser configuration, screenshots and logs. [Publisher verification](docs/publishing.md#2-validate-before-approving)
